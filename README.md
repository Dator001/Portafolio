# David Torres · Portafolio

Portafolio personal en español. Sitio estático en HTML, CSS y JavaScript, compatible con GitHub Pages y sin proceso de compilación.

## Vista local

Abre `index.html` en el navegador o sirve esta carpeta con `python -m http.server 8000` y visita `http://localhost:8000`.

## Contenido y edición

- `index.html`: perfil, experiencia, tecnologías, áreas de aporte, formación y contacto.
- `estilos.css`: paleta, tipografía y diseño adaptable.
- `script.js`: menú móvil, sección activa y año del pie.
- `assets/David-Torres-CV.pdf`: CV descargable.
- `Img/david-torres.jpeg`: fotografía actual a color. Se conservan las demás imágenes originales.

La experiencia y fechas corresponden al CV facilitado en septiembre de 2026. EPIK figura hasta septiembre de 2026; no se presupone un cargo vigente ni disponibilidad laboral. Las áreas de aporte describen experiencia profesional, sin inventar proyectos públicos ni métricas.

DM Sans y Manrope se cargan desde Google Fonts con alternativas locales si no hay conexión. No se requieren bibliotecas JavaScript ni servicios de formulario. El contacto utiliza correo, teléfono, LinkedIn y GitHub.

## Publicar en GitHub Pages

Sube los archivos al repositorio y configura Settings → Pages → Deploy from a branch, rama `main`, carpeta `/ (root)`. Las rutas locales son relativas y funcionan bajo `/Portafolio/`. Esta actualización local no publica ni modifica automáticamente el repositorio remoto.
